# Background removal quality checklist

Inspect at 100% zoom on both a light and a dark background. A result that looks clean on white may still have a pale fringe.

- [ ] The intended subject is complete: ears, fingers, straps, laces and paws.
- [ ] Empty gaps are clear, including spaces between limbs and handles.
- [ ] Hair and fur edges have no obvious leftover background color.
- [ ] Pale product edges are not cut away.
- [ ] Glass, reflections and translucent areas are acceptable for this use.
- [ ] There are no isolated background fragments outside the subject.
- [ ] The canvas does not crop the subject.
- [ ] Output format and dimensions match the destination requirements.
- [ ] The saved file reopens correctly in the destination app.

If a check fails, try a clearer original, simpler backdrop or stronger subject/background contrast. Use an editor for manual correction if necessary. A new export format or solid color does not restore missing image content.

For comparisons, use the same original, canvas and viewing scale. Do not infer overall accuracy or speed from one sample.
