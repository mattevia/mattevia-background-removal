# Mattevia 抠图指南与示例

[在线使用 Mattevia](https://mattevia.com) · [English](README.md)

这里整理透明图片、商品白底图和 iPhone HEIC 抠图的实用操作。仓库提供教程与演示素材，不包含线上服务源码、模型权重或公开 API SDK。

## 推荐操作

1. 上传一张清晰、主体完整的图片。
2. 抠图后对比原图，检查头发、鞋带、耳朵和主体内部空隙。
3. 分别放在浅色和深色背景上观察边缘。
4. 透明图片选择 PNG 或 WebP；JPG 无法保留透明通道。
5. 检查输出尺寸，下载后重新打开确认。

## 示例说明

[英文首页](README.md#before-and-after)展示商品、人像、宠物三组原图与结果。原图为 AI 生成的虚构演示素材，透明结果来自 2026 年 9 月 9 日的 Mattevia 实际处理，未手动修图。它们不是客户照片或效果保证。详见[来源说明](examples/SOURCES.md)。

细发丝、玻璃、反光与半透明材质可能丢失细节。换底色或导出格式不能恢复缺失部分。目前一次处理一张图片，不支持批量上传或 ZIP 导出。大图可能缩小，请以结果尺寸为准。
