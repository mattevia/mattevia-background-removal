# Contributing

Corrections, clearer instructions and reproducible image-format examples are welcome.

Open an issue describing the guide, the expected behavior, and the observed difference. For a pull request, explain what changed and check relative links.

Share only images you have permission to publish. Disclose generated images and editing steps. Do not submit customer photos, personal identifiers, credentials or private links. Strip private metadata before sharing. Example results must be labeled as observed samples, not universal quality or performance claims.

Keep links directly relevant to the guide. Unrelated promotional links and unsolicited advertising are not useful contributions.
